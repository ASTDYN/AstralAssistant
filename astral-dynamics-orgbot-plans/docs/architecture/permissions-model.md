# Permissions Model

Keep four concepts separate.

## 1. Discord roles

Server access/control.

Examples:

- Admin
- Member
- Recruit
- Trial Member
- Bot Manager

## 2. Rank labels

AstralDynamics rank labels for now:

- `#1`
- `#2`
- `#3`
- `#4`
- `#5`

These are not Discord roles by default.

## 3. Gameplay interest tags

Flexible operational tags.

Examples:

- Mining
- Salvage
- Cargo
- Combat
- Medical
- Logistics
- Exploration
- Racing
- RP
- Security
- Recovery

## 4. Website permissions

Only two tiers for V1:

- `ADMIN`
- `USER`

## Admin access rule

A Discord user is admin if they have the configured admin Discord role ID or a future configured admin override.
