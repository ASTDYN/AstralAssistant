# V1 Scope

## Product definition

AstralDynamics OrgBot is a Discord-first organization management system for a private Star Citizen Discord server.

V1 focuses on:

- member onboarding
- RSI handle / in-game name identity
- recruit approval
- rank/status management
- admin-controlled operation planning
- RAG-powered helpbot for AstralDynamics rules, lore, guidelines, onboarding, and beginner Star Citizen help
- admin-only warnings, incidents, and notes

## V1 includes

1. Discord bot shell
2. Single private Discord server configuration
3. User registration
4. RSI handle / in-game name field
5. Display name defaulting to RSI handle
6. Timezone
7. Gameplay interest tags
8. Recruit pipeline
9. Admin approval/rejection/trial status
10. Rank labels `#1` through `#5`
11. Discord role sync placeholders
12. Website permission tiers: `ADMIN`, `USER`
13. Admin operation planner
14. Member operation RSVP
15. Admin notes, warnings, incidents
16. Audit logs
17. Markdown-first KB
18. `/ask`, `/rules`, `/start-here`
19. Docker-host deployment

## V1 excludes

- certifications
- ship registry
- fleet planning
- live dispatch
- mission board
- training system
- after-action reports
- treasury/payout ledger
- diplomacy tracker
- org health analytics
- public/multi-server SaaS mode
- RSI login scraping

## Product principle

Build the backend website-ready, but do not build the website first.
