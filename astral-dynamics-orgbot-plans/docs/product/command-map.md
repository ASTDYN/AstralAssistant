# Command Map

## Member commands

| Command | Purpose | Access |
|---|---|---|
| `/register` | Create/link local member identity | Anyone in server |
| `/profile` | View own profile | Registered user |
| `/set-rsi-handle` | Set RSI handle / in-game name | Registered user |
| `/set-timezone` | Set timezone | Registered user |
| `/set-interests` | Set gameplay interest tags | Registered user |
| `/apply` | Submit recruit application | Anyone in server |
| `/op list` | List scheduled operations | Member |
| `/op view` | View operation details | Member |
| `/op join` | RSVP to operation | Member |
| `/op leave` | Leave operation RSVP | Member |
| `/help` | Show command help | Anyone |
| `/ask` | Ask KB/helpbot question | Anyone or member, depending on channel |
| `/rules` | Show rules | Anyone |
| `/start-here` | Show onboarding guidance | Anyone |

## Admin commands

| Command | Purpose |
|---|---|
| `/member` | View member details |
| `/applicant-list` | List recruit applications |
| `/approve-recruit` | Approve application |
| `/reject-recruit` | Reject application |
| `/set-trial` | Set trial member state |
| `/promote` | Move rank up |
| `/demote` | Move rank down |
| `/sync-roles` | Sync Discord roles |
| `/audit-member` | View member audit trail |
| `/op create` | Create operation |
| `/op roster` | View operation roster |
| `/op brief` | Generate/show operation briefing |
| `/op start` | Mark operation live |
| `/op complete` | Mark operation completed |
| `/op cancel` | Cancel operation |
| `/warn` | Create member warning |
| `/incident create` | Create incident |
| `/incident view` | View incident |
| `/member-notes` | View admin notes |
| `/add-note` | Add admin note |
